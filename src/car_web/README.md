# car_web

`car_web` 是精简的 FastAPI/RCLPy 桥，页面默认监听 `0.0.0.0:8000`。
它支持手动移动、急停、建图、地图保存、初始位姿、单点/多点导航和
经典/RL 模式选择。页面沿用三栏布局，左侧控制小车，中间显示地图和导航
工具，右侧显示底盘、雷达 TCP、扫描、里程计和导航状态。

## 启动

在 Jetson 工作区根目录执行：

```bash
ros2 launch car_web web.launch.py map="$PWD/maps/map.yaml"
```

浏览器访问 `http://192.168.4.1:8000`。整车启动时 `car_bringup` 会自动
启动 Web，无需重复运行。

## 任务与地图状态

Web 持久记录自己启动的建图或导航进程身份，服务重启后会核对 PID、启动时间
和命令再恢复管理。新一轮 bringup 会清理上一轮确认属于本项目的残留任务。
网页操作的互斥关系以这些受管任务为准，已有地图和 ROS 图中的短暂残留节点
不会阻止重新建图，只有当前网页启动的导航任务会阻止建图。

结束建图会先把地图写入临时文件，验证完整后替换正式地图，无论保存成功或失败
都会结束当前受管建图任务；失败时保留上一份有效地图并在页面显示原因。

手动速度使用 cm/s 和 °/s，默认线速度为 10cm/s，默认角速度为 60°/s。
后端保留最终 `/cmd_vel_move` 目标值与 ESP32 编码器反馈值用于诊断。
网页位置中的 yaw 使用 rad，实测角速度和 ROS 内部角速度使用 rad/s。

地图中的蓝色三角形表示实时小车位姿，蓝色圆点表示待执行目标，绿色圆点表示
已到达目标，红色圆点表示导航失败后放弃的目标。重新选择设置目标点会继续
累加目标，开始导航只执行尚未处理的蓝色目标。
清除最后目标点只删除队尾目标，点击清空目标点或结束导航会清空全部目标和
完成进度。建图时蓝色图标使用 slam_toolbox `/pose`，导航时使用 AMCL
`/amcl_pose`。手动模式使用最后可信地图位姿与里程计增量。

导航中触发急停会先锁住速度并暂停当前任务，目标与已完成进度会保留
；解除急停后不会自动移动，需要在页面点击继续导航。未启动导航时可以设置
当前位置，点击导航后会在启动期间暂时禁用。
单点、多点Action服务和地图TF全部就绪后，设置当前位置、设置目标点和
开始导航开放。后端会独立执行相同准入检查。

定位栈优先启动，导航栈默认延迟 3 秒，初始位姿会在 15 秒内重发直到 AMCL
确认。导航后台超过 15 秒仍未就绪时会完整停止本轮导航进程，等待 2 秒后
自动重试一次。
重试仍失败会结束定位并显示中文原因，不会一直停留在正在启动导航状态

地图位姿保存在与地图内容绑定的 `map.pose.json`。手动移动停止、急停、
建图开始、导航开始和继续、导航任务终态、结束导航及Web退出时记录当前位置
建图期间不会用新SLAM坐标覆盖旧地图位姿，新地图成功保存后才绑定最终位姿

导航模式默认选择经典模式。强化学习模型或推理环境未就绪时，对应模式按钮
保持灰色并显示原因，就绪后所选模式会原样传给导航启动参数。HTTP 成功和
失败响应都使用 JSON，意外服务异常会转换为中文错误信息。

多点目标通过标准 `FollowWaypoints` action 一次发送。小车连续 5 秒没有
产生 0.04m 有效位移时放弃当前目标并继续后续目标。目标可达性由 Nav2
按顺序判断，整批结束后失败目标变为红色且不会自动重试。
